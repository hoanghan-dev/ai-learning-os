# Progress & Mastery Tracking

## 1. Overview & Philosophy

In conventional self-study, progress is often tracked by vanity metrics: hours spent watching videos, number of pages read, or lines of code generated. These metrics give a false sense of achievement while masking fundamental skill stagnation.

In **AI Learning OS**, progress is defined exclusively by two quantitative vectors:
1. **Competency Level Progression**: Advancing along the ladder from **L1 (Recognition)** to **L6 (Architectural Design)**.
2. **Anti-Dependency Shift**: Driving reliance on AI down from **D4/D3** toward **D0 (Independent)** and **D1 (Documentation-Assisted)**.

---

## 2. The Continuous Feedback Loop

```text
Deliberate Practice (Workflows & Projects)
                    │
                    ▼
     Rigorous Assessment (Examiner & Rubrics)
                    │
                    ▼
      Identify Gaps & Misconceptions
                    │
                    ▼
         Log to Weakness Backlog
                    │
                    ▼
   Targeted Remediation & Spaced Retesting
                    │
                    ▼
       Promote Skill in Skill Matrix
```

## 4. Promotion Criteria (How to Level Up a Skill)

A skill cannot be marked as **Mastered (L4+ / D0–D1)** unless all three criteria are satisfied:
1. **Unassisted Implementation**: Built a functioning component or lab without AI code generation.
2. **Passed Active Recall**: Answered spontaneous conceptual and edge-case questions closed-book.
3. **Passed Code Defense**: Successfully defended the design and failure modes to the AI Examiner.
