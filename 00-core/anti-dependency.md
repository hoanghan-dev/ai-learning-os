AI Dependency Levels

D0 — Independent
    Tự làm được.

D1 — Documentation assisted
    Cần docs.

D2 — Hint assisted
    Cần AI hint.

D3 — Guided implementation
    AI hướng dẫn từng phần.

D4 — AI implementation
    AI viết phần lớn code.

D5 — Copy dependency
    Không hiểu code nhưng sử dụng.

Goal:
D0–D2 for skills being learned.
D3–D4 acceptable for unfamiliar production tasks.
D5 is a failure state.
